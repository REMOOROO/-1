# Анализ набора данных Cars Moldova: предсказание цены автомобиля

Лабораторная работа по анализу и предварительной обработке табличных данных.

**Задача:** регрессия, предсказание цены подержанного автомобиля (`Price(euro)`) по его характеристикам: марка, модель, год выпуска, пробег, объём двигателя, тип топлива, коробка передач, тип кузова.

**Что сделано**
- **Очистка данных:** удалены дубликаты (~9%), пробег, указанный в тысячах км, приведён к километрам, отсечены нереалистичные значения цены, пробега, года выпуска и объёма двигателя (осталось 34 666 из 41 007 строк).
- **Визуализация:** 6 графиков (hexbin-диаграмма, violinplot, lmplot, boxenplot, пузырьковая диаграмма по маркам, heatmap корреляций) с комментариями. Показано, что цена сильно скошена (нужен логарифм), нелинейно падает с возрастом и выше у автоматических коробок, гибридов, электромобилей и премиальных марок.
- **Статистика:** `describe`, асимметрия, корреляции Пирсона и Спирмена с целевой переменной, `groupby` + `agg` по категориальным признакам. Самый сильный числовой предиктор — возраст автомобиля.
- **Предобработка:** `Pipeline` + `ColumnTransformer` с отдельной обработкой для каждой группы признаков (стандартизация, Yeo-Johnson для скошенного объёма двигателя, One-Hot с группировкой редких категорий, частотное кодирование модели). Предварительно данные разбиты на train/test (80/20), преобразователи обучены только на train. Реализованы три собственных трансформера.

**Файлы**
- `cars_moldova_analysis.ipynb` — основной блокнот
- `cars_moldova_train_prepared.csv`, `cars_moldova_test_prepared.csv` — обработанные обучающая и тестовая выборки (целевая переменная — `LogPrice`, то есть log(1 + цена))

**Библиотеки:** pandas, numpy, matplotlib, seaborn, scikit-learn
